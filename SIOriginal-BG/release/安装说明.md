# SIOriginal-BG v3.0.0-BG 安装说明

Release：https://github.com/Cqjzhws/SpeedIntensifier/releases/tag/sioriginalbg-v3.0.0
构建：GitHub Actions（macOS / Xcode，minos 14.0 / sdk 17.5，arm64）

## 文件

| 文件 | 大小 | 用途 |
| --- | --- | --- |
| `SIOriginalBG.dylib` | 160928 | 保活插件本体，TrollFools 注入目标 App |
| `SIOriginalBG.ipa` | 136330 | 配置 App（真后台），TrollStore 安装 |

两个文件都由 Actions 产物原样下载（lief 校验：dylib = MH_DYLIB/arm64/install_name `@rpath/SIOriginalBG.dylib`/`__text` 位于 0x4000；ipa 内可执行文件 0755 + ad-hoc 签名 + Info.plist + 图标）。

## 安装

1. **配置 App**：TrollStore 安装 `SIOriginalBG.ipa`（显示名「真后台」，bundle id `com.local.sioriginalbg`）。
   界面：总开关 / 场景伪装 / 音频断言三个开关 + 排除名单 + App 专属覆盖 + 扫描 + 保存（即时生效）+ 恢复出厂 + 注销。
2. **注入**：TrollFools 把 `SIOriginalBG.dylib` 注入目标 App。
   ⚠ 原来注入 `SIOriginal.dylib` 的位置换成它，**不要两个同时注入同一个 App**（功能已覆盖，同注会双份 hook）。
3. **配置**：保存后走 Darwin 通知 `com.local.sioriginalbg.settingschanged` 热重载，无需注销 App。
   配置文件 `/var/Managed Preferences/mobile/com.local.sioriginalbg.plist`（与旧版 `com.apple.UIKit.plist` 不互通，倍率参数已不存在）。
   删掉整个 plist = 回出厂默认（三项全开、名单清空）。

## 生效自检

控制台（Console.app 连真机，或 `idevicesyslog`）过滤 `[SIOBG]`：

- 启动：`[SIOBG] v3.0.0-BG loaded in <bundle id>: active=1 scene=1 audio=1 audioMode=1`
- 后台化被拦截：`[SIOBG] swallowed backgrounding scene diff`
- 音频起停：`[SIOBG] audio keep-alive started (audioMode=1)` / `watchdog started, interval=3.0s`
- 没 audio 后台模式又关了场景伪装：启动行尾带 `(WARNING: no audio mode & no scene engine)`

## 排障

- 某个 App 不要保活：排除名单加它的 bundle id（结尾 `*` 表示前缀匹配，如 `com.tencent.*`）。
- 微信疑似「两个视频画面」时，只关微信的场景伪装、保留音频断言：
  App 专属覆盖里加一行 `com.tencent.xin scene=0 audio=1`。
- 改了配置没反应：确认 plist 写成功（App 里保存后状态栏提示），再杀目标 App 重开。
